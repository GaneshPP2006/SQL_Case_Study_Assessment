\# Music Store SQL Analysis



\## Project Overview



This project uses MySQL to analyze a digital music store's sales data, customers, artists, tracks, genres, and invoices.



\## Tools Used



\- MySQL 8.0

\- MySQL Workbench

\- SQL



\## Database



The project uses the Chinook sample database, which includes artists, albums, tracks, customers, invoices, invoice line items, and genres.



Source: https://github.com/lerocha/chinook-database



\## Business Questions



1\. What is the total sales value and number of invoices?

2\. Which countries generate the most sales?

3\. Which customers spend the most?

4\. Which artists generate the highest sales value?

5\. Which tracks sell the most units?

6\. Which music genres generate the most sales?

7\. How do sales vary by month?



\## SQL Skills Demonstrated



\- SELECT, WHERE, GROUP BY, and ORDER BY

\- Aggregate functions: COUNT, SUM, and ROUND

\- JOIN operations across multiple tables

\- Subqueries

\- Date formatting and monthly aggregation

\- Business KPI calculations
